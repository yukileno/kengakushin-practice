# 県学診 れんしゅう（旧版）

> **メインのアプリは [思考力育成ブロックワールド（kengakushin-bw）](https://github.com/yukileno/kengakushin-bw) です。**
> https://yukileno.github.io/kengakushin-bw/
> このリポジトリは旧版として残しています。**新しい問題の追加・修正は、kengakushin-bw の `quiz/data/` で行います**（ここを直しても、bw には届きません）。
> 先生用の「先生モード」（スキップ・ぜんぶの教科を出す）も、bw 側にあります。

小学5年向けの県学診の練習アプリ（ブラウザだけで動く。記録は端末内のみ）。

- `index.html` … 児童用アプリ（達成ドット絵・ロック・お祝いつき）
- `data/` … 算数・社会・国語・資料の読み取り・全国学力テストへの道・国語の読解の問題

県が配布した問題・正答例・メール等は、このリポジトリに入れない。
